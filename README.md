# NEXT STL — Android

Visualizador de peças STL (joalheria 3D) para Android. Abre arquivos `.stl`
recebidos no WhatsApp, mostra a peça em 3D e o peso estimado em ouro 18K e
prata 925.

- Toque num `.stl` no WhatsApp → **Abrir com → NEXT STL**.
- Gire com um dedo, zoom com dois dedos.
- Troque a cor (laranja, ouro, prata) e o fundo (preto/branco).

## Baixar o app

O instalador (APK) é gerado automaticamente a cada atualização. Baixe a versão
mais recente em **[Releases → latest](../../releases/latest)** (arquivo
`NEXT-STL.apk`).

A compilação roda sozinha pelo GitHub Actions (`.github/workflows/build.yml`).
